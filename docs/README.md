# backlog-helper — документация

Шаблон портала для **сбора обратной связи, приёма сообщений об ошибках и формирования
продуктового бэклога**. Референс по публичной части — [feedback.clickup.com](https://feedback.clickup.com)
(это white-label [Canny](https://canny.io)).

Важно: референс покрывает только сбор идей — баги ClickUp в портал не принимает вовсе
(ссылка «Report a bug» уводит на форму саппорта), а бэклог ведёт снаружи. Две трети
нашего фокуса референсом не покрыты и спроектированы отдельно:
[05-bug-intake.md](05-bug-intake.md) и [06-backlog.md](06-backlog.md).

Модель использования: этот репозиторий — **шаблон**. Под каждый продукт делается форк/клон,
в нём меняется только конфигурация и оформление. Логика остаётся общей и мержится из апстрима.

## Три контура продукта

```
   СБОР                    ТРИАЖ                   БЭКЛОГ
обращения  ──────────►  решение по каждому  ──────────►  единицы работы
(портал, виджет,        (подтвердить, смержить,     (приоритет, связь N:M
 email, саппорт, API)    запросить инфо, отклонить)   с обращениями, синк с трекером)
     ▲                                                        │
     └──────────── письма, роадмап, changelog ◄───────────────┘
                        (замыкание цикла)
```

Третий контур — то, чего нет в референсе, и то, ради чего продукт вообще нужен:
без него портал остаётся стеной пожеланий.

## Глоссарий

- **Board (доска)** — верхнеуровневый раздел портала: «Запросы функций», «Ошибки», «API».
- **Post / обращение** — единица входящего сигнала. Имеет **тип** (`idea`, `bug`, `problem`, `question`, `security`), статус и голоса.
- **Vote (голос)** — «мне тоже нужно» для идеи, «у меня тоже» для бага. Один пользователь = один голос на пост.
- **Severity** — оценка серьёзности **репортером** (насколько мешает ему). **Priority** — оценка **команды**. Это разные поля, их нельзя объединять.
- **Category / Tag** — двухуровневая навигация внутри доски (категория — иерархическая, тег — плоский).
- **Status** — публичная стадия обращения (`open → planned → building → beta → completed`).
- **Backlog item** — внутренняя единица работы. Связан с обращениями N:M. Имеет свой внутренний статус, который маппится на публичный.
- **Insight** — цитата пользователя из источника вне портала (звонок, тикет, чат), привязанная к обращению или элементу бэклога.
- **Fingerprint** — подпись ошибки для авто-дедупликации багов.
- **Roadmap** — публичная сводка обращений по статусам со всех досок.
- **Changelog** — лента релизов, связанная с закрытыми обращениями.
- **Merge** — склейка дубликата в основное обращение с переносом голосов и подписчиков.
